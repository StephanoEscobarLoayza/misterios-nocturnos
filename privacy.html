Misterios Nocturnos

Privacy Policy

Effective date: August 3, 2026 Last updated: August 3, 2026

1. About This Application

Misterios Nocturnos is a personal desktop application developed by Stephano Escobar Loayza for the exclusive purpose of managing the creator's own YouTube and TikTok content. The application is not distributed publicly and has no registered end-users other than its sole developer.

This application operates entirely on the developer's local machine. It does not run a public server, does not operate a database, and does not transmit personal data to any third party.

2. Information We Access

When connected to TikTok via OAuth 2.0, the application requests the following permission scopes:

  • user.info.profile — display name and profile picture
  • user.info.stats — follower count, following count, video count, and total likes
  • video.list — list of videos published on the connected TikTok account
  • video.upload — ability to upload new videos to the connected TikTok account

This data is used exclusively to display channel statistics and upload content on behalf of the account owner (the developer), within the desktop application.

3. How We Store Data

Authentication credentials issued by TikTok (OAuth access token and refresh token) are saved to a local JSON file named tiktok_token.json on the developer's own computer. This file is protected by the operating system's standard file permission model and is never uploaded to any server or cloud service.

Profile statistics and video metadata retrieved from the TikTok API are held in memory during the application session only. No data is written to a remote database or analytics service.

4. Data Sharing and Third Parties

We do not sell, rent, share, or disclose any data to third parties. The only external system that receives data is the TikTok API itself, as part of the OAuth 2.0 authorization flow and subsequent API calls initiated by the application owner.

All communication with TikTok's servers uses HTTPS, as required by TikTok's API specification.

5. Data Retention and Deletion

Stored tokens can be revoked and deleted at any time by:

  • Deleting the tiktok_token.json file from the local file system, or
  • Revoking the application's access directly from the TikTok account security settings at tiktok.com/setting.

Once revoked, the application cannot make any further API calls until the OAuth flow is restarted by the account owner.

6. Cookies and Tracking

This application is a native desktop application and does not use cookies, web beacons, pixel tracking, or any similar technology. No analytics SDK is embedded.

7. Children's Privacy

This application is not directed at children under the age of 13. It is a personal productivity tool used solely by its developer and is not available for download by the general public.

8. Changes to This Policy

If this policy is updated, the "Last updated" date at the top of this page will change. Because this application is personal and has a single user (the developer), no additional notification mechanism is required.
